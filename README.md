# Infoesearch — Media Management Site

Cinematic marketing site for **Infoesearch**, a media intelligence, localization, and trust & safety organization.

## Design direction

- Palette: **red / white / black**
- Motion: GSAP ScrollTrigger — pinned approach story, horizontal product side-slides, literature chapter scroll
- Type: Syne (display) · Instrument Serif (emphasis) · IBM Plex Mono (labels)

## Content source

Adapted from the working Infoesearch homepage brief (`madcapmedia.in/infoesearch`) and [infoesearch.com](https://infoesearch.com/).

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

Open `http://localhost:5173` for the local preview.
